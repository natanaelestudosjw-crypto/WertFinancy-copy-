# Wert

**Wert** é um sistema de controle financeiro pessoal desenvolvido com PHP e MySQL, criado para facilitar o gerenciamento de receitas, despesas, contas, cartões e metas financeiras.

O projeto tem como objetivo unir **utilidade no dia a dia** com **aprendizado prático de desenvolvimento web**, evoluindo gradualmente de um sistema CRUD simples para uma aplicação completa.

### Funcionalidades planejadas

* Cadastro e autenticação de usuários
* Dashboard financeiro
* Controle de receitas e despesas
* Categorias personalizadas
* Gerenciamento de contas
* Controle de cartões de crédito e faturas
* Compras parceladas e despesas recorrentes
* Metas financeiras
* Orçamentos por categoria
* Relatórios e gráficos
* Pesquisa e filtros de transações
* Importação e exportação de dados
* API REST própria
* Integrações com APIs externas
* Sistema responsivo e, futuramente, PWA

### Tecnologias

* PHP
* MySQL
* PDO
* HTML5
* CSS3

O desenvolvimento será realizado de forma incremental, utilizando o projeto como uma oportunidade para estudar **PHP, SQL, arquitetura MVC, APIs, autenticação, segurança e boas práticas de desenvolvimento**.

> **Wert** significa “valor” em alemão — representando a ideia de compreender, organizar e dar valor aos próprios recursos financeiros.
